# AGENTS

Instructions for agents authoring OpenSpec artifacts (proposal, specs, design, tasks) in this repository.

## Diagram-first

- Lead with the diagram: wherever a point can be illustrated, put the diagram before the text that describes it.
- Favor diagrams over prose: they are faster to understand and keep design docs shorter.
- Write diagrams as Mermaid in fenced ```mermaid blocks. GitHub renders Mermaid natively in Markdown, so diagrams display correctly in PRs and the web UI without extra tooling.
- Match the diagram type to the subject: flowcharts for control flow, sequence diagrams for interactions, state diagrams for state models.
